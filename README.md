# 🌸 Amaranthie - Company Profile Website

Amaranthie adalah sebuah website mini tentang toko bunga yang menyediakan berbagai macam bunga, baik satuan maupun dalam bentuk bouquet.  
Website ini dibuat sebagai **mini project** dengan tujuan menampilkan profil perusahaan, visi dan misi, serta menyediakan form komunikasi untuk stakeholder.

---

## 🛠️ Teknologi yang Digunakan
- **HTML5** – Struktur halaman.
- **Tailwind CSS** – Styling & responsive design.
- **JavaScript (Vanilla)** – Popup, validasi form, dan manipulasi DOM.
- **Git & GitHub** – Version control dan deployment.

---

## 🚀 Workflow Project
1. Menyelesaikan fitur sesuai requirement.
2. Memastikan design responsive untuk mobile maupun desktop.
3. Deploy website menggunakan **GitHub Pages**.
